## 変更履歴を「誰が・いつ・何を・どのように」追う方法

このリポジトリでは、**Gitの履歴**が公式の変更履歴です。

### まず見る（人間が読む用）

- **誰が**: commit の Author
- **いつ**: commit の Date
- **何を**: commit message（タイトル）
- **どのように**: 差分（diff）

確認方法:

- `git log`（コミットの一覧）
- `git show <commit>`（その1回の修正内容）

### まとめて一覧（コマンド1つ）

このリポジトリには、一覧表示用のスクリプトがあります。

```bash
bash scripts/audit.sh
```

出力には以下が含まれます。

- commit hash
- 日時（ISO形式）
- 作者
- タイトル
- 変更ファイル一覧（A/M/D）
