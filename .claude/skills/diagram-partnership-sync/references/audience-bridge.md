# 読者ブリッジ（2人が同じ1枚を読む）

## 目次

- ゴール
- ラベルと視線の導線
- よくある失敗と回避

---

## ゴール

- **講師（AI寄り）** と **SNSマーケター** が、**同じURLまたはHTMLファイル**を開いたとき、それぞれが **自分の担当領域の次の一手** を誤解なく取れる。
- 「一方だけ向けの内部資料」にしない。秘密情報はユーザー指示があれば除外し、**共有前提の抽象度**に落とす。

---

## ラベルと視線の導線

1. **ヒーロー直下**に、次のいずれかを置く:
   - **一言サマリー**（太字1文）: 「今日決まったこと」
   - **ミニ図**（アイコン＋矢印）: 論点→決定→次アクション

2. **バッジ**で領域を色分けする（意味は図例で固定）:
   - 例: `決定` / `相談中` / `次アクション` — 文言は会議に合わせてよいが、**同じ図内で意味を統一**する。

3. **「誰向け」注記**は、用語ボックスや詰まりやすい段落にだけ付ける。全段落に付けない（ノイズになる）。

4. **ネクストアクション**は表またはカードグリッドで:
   - 列または行: 担当（名前または役割） / やること / 期限 / 依存（先に必要なこと）

---

## よくある失敗と回避

| 失敗 | 回避 |
|------|------|
| 決定とタスクが同じ箇条書きに混在 | セクションを分け、見出しで役割を固定 |
| マーケ用語だけの「施策名」一覧 | 各行に「目的（1語）」を添える |
| AI実装話が長文化 | 「今回の会議での意味」に切り詰め、詳細は別ドキュメントへ誘導する一文を入れる |
| どちらがオーナーか不明 | 各アクションに1人（または1ロール）を必ず紐づける |
