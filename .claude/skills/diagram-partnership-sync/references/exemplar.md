# 模範パターン（会議サマリー図解）

## 目次

- 成功するページの骨格
- 情報の優先順位
- 品質チェックリスト（印刷・共有）

---

## 成功するページの骨格

```
1. ヒーロー
   └─ タイトル・日付（任意）・一言で「何の会議か」

2. サマリー1枚（ビジュアル）
   └─ 決定 → 次アクション の流れをアイコン＋矢印で

3. 決定事項
   └─ カードまたは番号リスト。1項目＝1決定

4. ネクストアクション
   └─ 担当・内容・期限・依存。表推奨

5. 未決・継続論点（あれば）
   └─ 「次回」「要確認」を明示

6. 用語ボックス（必要な語だけ）
   └─ AI向け補足 / マーケ向け補足 を混在させず、見出しで分ける

7. 参考リンク（任意）
```

---

## 情報の優先順位

1. **決定事項**と**ネクストアクション**を最優先。ここが薄い図解は失敗。
2. **背景説明**は短く。長い文脈は「別途ドキュメント」に誘導する1文で足りる。
3. **両者に不要な詳細**（実装ログ、個人メモ）は入れない。ユーザーが明示した場合のみ。

---

## 品質チェックリスト（印刷・共有）

### 内容

- [ ] 決定事項が、読み終わったあと**一文で言い直せる**
- [ ] ネクストアクションが、**誰が・何を・いつまでに**追える（未定は明示）
- [ ] AI用語・マーケ用語に、相手側向けの補足がある
- [ ] ファーストスクロール以内に「次にやること」が見える

### 技術（creating-visual-explainers準拠）

- [ ] 絵文字を使っていない（Lucideのみ）
- [ ] テンプレートの `head`・禁止されている `script` / `style` 追加をしていない
- [ ] インタラクティブ要素を入れていない
- [ ] スマホ幅で読める（横並びはモバイルで縦に落ちる想定）

### レビュー後

- [ ] Phase 7 の**致命的**指摘はすべて対応済み
